At [useR! 2014](http://user2014.stat.ucla.edu/) [Ramnath Vaidyanathan](https://github.com/ramnathv) gave a tutorial and a presentation on one of his current project, [rCharts](http://ramnathv.github.io/rCharts/). This R package allows you to create, customize and share interactive visualizations straight from R. rCharts leverages several existing javascript visualization libraries such as [polychart](https://www.polychart.com/), [MorrisJS](http://morrisjs.github.io/morris.js/), [NVD3](http://nvd3.org/), [xCharts](http://tenxer.github.io/xcharts/), [HighCharts](http://www.highcharts.com/), [leaflet](http://leafletjs.com/), and [Rickshaw](http://code.shutterstock.com/rickshaw/), providing R users a fantastic array of new features and visualization styles.

rCharts also provides a convenient method to share these charts, either in standalone mode, by using a [Shiny](/shiny-r-made-interactive-user-2014/) application, or even in a blog post using [knitR](/yihui-xie-the-user-2014-interview/)! Continuing with the theme of the conference of [R as an interface](/john-chambers-user-2014-keynote/), Ramnath has succeeded in creating a powerful system to smoothly move between the familiar lattice plotting interface and the best available visualization libraries.

In this talk, Ramnath provides a high level overview of rCharts, as well as providing a deep dive into the kinds of visualizations possible with this tool - including the interactive visualizations now at your fingertips. From [barcharts](http://rcharts.io/gallery/#visualizationType=bar%20chart) to [mapping](http://rcharts.io/gallery/#visualizationType=map), from static to interactive, Ramnath covers many common use cases with this package, and we encourage you to follow along with the video below using his provided slides from the original talk.
